# WARP Endpoint Hunter

Advanced WARP / AmneziaWG Endpoint Scanner and WG Config Generator for Termux / Android.

**Current Release: v1.0.0**

## Quick Start

Run the latest version directly in Termux:

```bash
curl -fsSL https://raw.githubusercontent.com/ezedin63/warp-endpoint-hunter/main/warp-endpoint-hunter.sh -o $PREFIX/tmp/w.sh && bash $PREFIX/tmp/w.sh
```

## Features

- WARP Endpoint Scanner
- AmneziaWG endpoint detection
- WARP Auto Config Generator
- Automatic WARP account registration
- Automatic WARPSCOUT installation
- Automatic WARPSCOUT update
- Automatic dependency installation
- ARM64 / AARCH64 support
- Endpoint latency testing and ranking
- Top endpoint detection
- Native AmneziaWG configuration generation
- Automatic configuration storage
- Termux / Android optimized
- GitHub-based public distribution

## Requirements

- Android
- Termux
- Internet connection
- ARM64 / AARCH64 recommended

The script automatically checks and installs required dependencies when needed.

## Main Menu

1. Endpoint Scanner
2. WARP Auto Config Generator
3. View Latest Scan
4. View Generated Configs
5. Version Information
0. Exit

## Security

- Private WARP account files are kept locally.
- Private keys are not included in the GitHub repository.
- Generated configuration files remain on the user device.
- No user credentials are hard-coded into the public script.
